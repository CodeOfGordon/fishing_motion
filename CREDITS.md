# Credits

Every file in `assets/` is listed here with its licence and source URL.
`tests/test_credits.py` fails if a file is missing from this list.

## Art
All art is original and drawn in code (this repository). There are no image files.

## Fonts
- **pygame-ce default font** (FreeSansBold, GNU FreeFont). GPL-3.0-or-later with the font
  exception. It's loaded through `pygame.font.Font(None)` from the pygame-ce package and isn't
  copied into this repository. https://www.gnu.org/software/freefont/license.html

## Sound effects
All sound effects are synthesised in code at startup (`fishing/audio/synth.py`,
`fishing/audio/recipes.py`). There are no sound files.
